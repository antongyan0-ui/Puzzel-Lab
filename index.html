数据迁移教程

你的做题记录存储在浏览器的本地存储中，与域名绑定。换域名后数据不会自动迁移，需要手动操作。

第一步：从旧站导出数据

  1. 打开旧站：https://listen-cloze-edit.surge.sh/
  2. 登录你原来的账号
  3. 点击右上角用户菜单 →「导出备份」
  4. 保存下载的 JSON 文件到电脑

第二步：在新站导入数据

  1. 在当前站点注册或登录（可以使用原用户名）
  2. 点击右上角用户菜单 →「导入备份」
  3. 选择刚才下载的 JSON 文件
  4. 所有挖空记录、文档、词汇将恢复

第三步：开启云端同步（防止再次丢失）

  1. 点击用户菜单 →「云端同步设置」
  2. 输入 JSONBin API Key（免费注册：jsonbin.io）
  3. 设置后数据自动云端备份，换域名/设备不再丢失
提示：如果旧站也无法登录（忘记了密码），可以在旧站使用「找回密码」功能重置后再导出。旧站地址：点击前往

云端同步设置

第一步：获取 API Key
1. 注册 JSONBin.io 免费账号（每月 10,000 次请求）
2. 登录后在 控制台 复制你的 X-Master-Key
3. 粘贴到下方输入框并保存
第二步：跨设备同步
保存 API Key 后将自动生成同步码。在其他设备上输入相同的 API Key 和此同步码即可同步。 如果你已在其他设备上启用过云端同步，请输入该设备的同步码。否则留空将自动创建新的同步码。
