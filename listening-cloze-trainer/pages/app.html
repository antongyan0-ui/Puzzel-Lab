云端同步设置

第一步：获取 API Key
1. 注册 JSONBin.io 免费账号（每月 10,000 次请求）
2. 登录后在 控制台 复制你的 X-Master-Key
3. 粘贴到下方输入框并保存
第二步：跨设备同步
保存 API Key 后将自动生成同步码。在其他设备上输入相同的 API Key 和此同步码即可同步。 如果你已在其他设备上启用过云端同步，请输入该设备的同步码。否则留空将自动创建新的同步码。
